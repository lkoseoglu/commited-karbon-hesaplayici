# commited-karbon-hesaplayici

Commited turizm karbon hesaplayıcıları — GitHub Pages ile yayınlanır, commitedevents.app'e iframe ile gömülür.

- `turizm-karbon-hesaplayici.html` — **Turizm Karbon Hesaplayıcı** (otel HCMI v2.0 + acente) — sitedeki sürüm
- `turizm-karbon-hesaplayici-v6.html` — Turizm hesaplayıcısının **yeni sürümü (önizleme)**: resmî HCMI v2.0 motoru,
  Türkiye resmî elektrik faktörü, enerji defteri, Türkçe sayı girişi, veri kontrolü, NZMFH net sıfır patikası
- `kapsam3-karbon-hesaplayici.html` — **Kapsam 3 Karbon Hesaplayıcı** (turizm tedarik zinciri, 3.1 + 3.4)

Testler: `npm install && npm test && npm run test:e2e`

Yazılım ekibi için ayrıntılar: [README-yazilim-ekibi.md](README-yazilim-ekibi.md)
